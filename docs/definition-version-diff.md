# 对比流程发布版本

在「流程定义」打开目标流程的「版本与治理」，选择「版本对比」。选定基准和目标版本后点「比较版本」。可交换两侧，也可用「目标选最新」选择当前有权查看的最新发布版本。

结果按流程配置、节点、审批规则、路由、表单和画布布局展示。筛选变化类型或节点可以缩小范围。点击差异行的节点名称可在只读画布中定位，删除节点显示在基准图中。版本选用仍通过治理面板操作。

比较使用版本列表已授权返回的快照，读取需要宿主授予对应流程与版本的 `DefinitionReadSensitive`。节点以 ID 对齐，表单字段以字段 Key 对齐。对象键顺序和格式空白无差异，审批顺序、路由和字段排列的变化会显示。无法唯一对应的条件分支以增删显示。
