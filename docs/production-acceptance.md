# 当前版本上线验收边界

项目尚未正式使用，数据库从当前 InitialApproval 初始化；没有旧环境升级、回填或数据拆分流程。当前实测结果和未执行边界以 [完成报告](embedded-approval-completion.md) 为准。

上线时验证真实宿主认证/目录/权限映射、新库初始化、完整审批闭环、共享业务事务、幂等与并发、备份恢复和宿主事件处理器。只运行一个审批 Worker，外部副作用用稳定事件 ID 幂等。

测试和包消费者使用独立临时数据库，不会删除或重建用户已有数据库。正常备份、就绪检查和审批历史保护继续保留；真实 MySQL、SQL Server、PostgreSQL 的结果必须来自各自实测日志。
